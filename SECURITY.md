# Security policy

This repository is a research prototype and is **not** a production security boundary.

Do not connect the starter code to real credentials, financial systems, production shells, private inboxes, or destructive tools.

When adding real model providers or tool protocols:
- use test credentials and isolated environments;
- default to deny for irreversible actions;
- treat external content as untrusted;
- preserve an auditable record of decisions;
- document every trust assumption;
- never publish secrets or exploit details that would create avoidable real-world harm.

Report security issues privately to the project maintainer before public disclosure.
