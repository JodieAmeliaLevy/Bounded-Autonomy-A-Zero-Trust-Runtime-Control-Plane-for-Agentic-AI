# Committed results

Every file here is the output of a deterministic experiment, regenerated by
one command:

    python -m experiments.run_all

`INDEX.json` lists which command produces which file. CI runs the same
command and fails if a committed file is stale.

These are committed on purpose, and the reasoning is narrower than it might
look. Generated results were previously ignored so that one local run could
not become canonical evidence. That argument holds for anything stochastic
and does not apply to this set: every experiment here uses scripted
providers and synthetic environments, so the output is reproducible rather
than sampled, and a findings document that quotes a number should ship the
artefact behind it.

Real-model results are a different case and stay out of the repository, for
exactly the original reason. `results/real_model_*.json` is gitignored.
